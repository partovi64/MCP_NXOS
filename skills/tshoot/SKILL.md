# TSHOOT Skill

1. Define symptom, service, source, destination, protocol, start time, and change history.
2. Establish whether the issue affects an endpoint, VLAN, device, routing domain, or site.
3. Gather relevant read-only evidence.
4. For each hypothesis, record expected evidence if true/false, actual observations, contradictions, and the next discriminating test.
5. Distinguish confirmed facts, probable causes, and unverified hypotheses.
6. Never treat temporal correlation alone as proof of causation.

Safety: no configuration changes, reloads, clears, unsafe debug actions, or unbounded probes.
