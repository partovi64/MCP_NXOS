# SHOW Skill

Use the smallest approved read-only command set. Record device alias, exact command, collection time, status, and truncation. Do not infer historical state from a single snapshot. If syntax is unsupported, report that fact and select an approved alternative.

Areas: platform (`show version`, `show clock`), interfaces, routing, OSPF, BGP, VLANs, trunks, STP, and logs. Verify platform-specific syntax before extending the allowlist.
